Security & Privacy

Seedhi baat: Bean par aap ki chats end-to-end encrypted hain. Is ka matlab hai ke message sirf aap aur jin ko aap ne bheja, unke devices par khulta hai. Bean ka server, Neyo, ya koi aur unhe nahi parh sakta.

🔒 Kya end-to-end encrypted hai

  • Har direct chat aur har group: text, edits aur reactions
  • Photos, files aur voice notes (har file ki apni alag key)
  • Voice/video call ka setup (is liye server call ke beech mein nahi aa sakta). Call ki awaaz aur video WebRTC se seedha encrypted jaati hai.

👀 Server kya dekh sakta hai (metadata)

Encryption message ke andar ki baat chhupati hai, ye cheezein nahi:

  • Aap kis se baat karte hain, kab, aur kitne messages
  • File ka size, group ka naam aur members
  • Aap ka naam, photo, online status aur Away note
  • Aap ka IP address (hosting logs mein)

⚠️ Kya encrypted nahi

  • Neyo chat: Neyo AI hai. Us ki chat ke messages jawab ke liye Google Gemini ko jaate hain. App mein is par saaf label hai. Passwords, card ya bank details Neyo ko kabhi na likhein.
  • Purane messages: Bean v2.0 se pehle wale messages par "Not encrypted" likha hota hai.
  • Away note (Ghost): ye status ki tarah contacts ko dikhta hai. Ghost aap ke messages kabhi nahi parhta aur na jawab deta hai.

🗝️ Aik password, sab kuch

Aap ka Bean password hi aap ki encryption key ka lock hai. Login karte hi chats khud khul jaati hain, koi alag lock yaad nahi rakhna. Key ka backup aap ke browser mein hi password se lock hota hai (Argon2id + AES-256-GCM), aur server par sirf lock shuda backup jaata hai.

Imandari se: login ke waqt server aap ka password check karta hai, is liye nazariyati taur par agar koi Bean ka server hi qabze mein le kar login ke waqt passwords chura le, to woh backup khol sakta hai. Database leak hone par bhi messages nahi khulte. Lamba, alag password rakhein.

Password bhool gaye to purani encrypted chats wapas nahi aa saktin. Bean ke paas koi "master key" nahi hai.

✅ Khud check karein

  • Safety number: kisi bhi chat ki info mein 60 digits ka number hai. Dono logon ke phone par same ho to koi beech mein nahi.
  • Key change warning: kisi contact ki key badle to Bean foran batata hai.
  • Build number: Settings mein Bean ka version aur build dikhta hai.

🛡️ Account ki hifazat

  • Passwords Argon2id se hash hote hain; login par koshishon ki had (rate limit) hai
  • Session cookie HttpOnly + Secure; "Log out all devices" Settings mein
  • Password badalne par baaqi devices se sign out
  • Koi ads, trackers ya bahar ke scripts nahi; fonts bhi Bean khud serve karta hai; sakht Content-Security-Policy

Imandari se: limits

  • Bean web app hai: aap us code par bharosa karte hain jo bean.signaturesi.com bhejta hai.
  • Agar aap ke phone/computer mein virus ho, ya koi screenshot le, to encryption us se nahi bacha sakti.
  • Bean ka independent security audit abhi nahi hua.

Masla report karein

Security ka koi masla mile to security.txt mein diye gaye raste se batayein. Agar kabhi data ka masla hua to hum users ko jald az jald aur saaf batayenge.
